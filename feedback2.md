Peer Feedback

Strength
The task design in the seven houses is very creative. Each house has its own unique mechanic, and the variety keeps the gameplay fresh and engaging.

Risk
The connections between tasks are not yet fully implemented, which may cause players to feel lost or unsure of what to do next. Performance also drops in a few areas with many objects.

Question about contribution
How did you divide the work between scene building, scripting, and UI design?

My answer
I built the scenes and set up most of the interactive triggers myself. The more complex logic, like the card game and piano sequence, was done with reference to AI-generated code, which I then adapted to fit the project.

Practical suggestion for Session 4
Focus on linking all five tasks into a clear main path. Also add a simple task tracker or UI hints so players always know which house to go to next. Improve the response time of button interactions, especially in the card game.
